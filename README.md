# FreeCodeCamp Python Projects

This repository contains a collection of Python projects completed as part of the FreeCodeCamp Scientific Computing with Python certification and additional programming practice.

## Projects Included

### 1. Budget App

A budgeting application built using Object-Oriented Programming principles.

**Features**

* Create budget categories
* Deposit and withdraw funds
* Transfer money between categories
* Check balances
* Generate spending charts

**Concepts Demonstrated**

* Classes and Objects
* Object-Oriented Programming (OOP)
* Data Structures
* String Formatting

---

### 2. Polygon Area Calculator

A program that models rectangles and squares and performs geometric calculations.

**Features**

* Calculate area
* Calculate perimeter
* Calculate diagonal length
* Generate text-based shape drawings
* Determine how many shapes fit inside another shape

**Concepts Demonstrated**

* Inheritance
* Method Overriding
* Mathematical Computations
* Object-Oriented Programming

---

### 3. Hash Table Implementation

A custom hash table implementation using Python dictionaries and collision handling techniques.

**Features**

* Add key-value pairs
* Remove entries
* Search for values
* Handle collisions

**Concepts Demonstrated**

* Hash Functions
* Data Structures
* Dictionaries
* Algorithm Design

---

### 4. Tower of Hanoi Solver

A recursive solution to the classic Tower of Hanoi problem.

**Features**

* Solves Tower of Hanoi for any number of disks
* Displays rod states after each move
* Demonstrates recursive problem-solving techniques

**Concepts Demonstrated**

* Recursion
* Divide and Conquer
* Algorithm Analysis
* Problem Solving

---

### 5. User Configuration Manager

A simple settings management system using Python dictionaries.

**Features**

* Add settings
* Update settings
* Delete settings
* View current configuration

**Concepts Demonstrated**

* Dictionaries
* Functions
* Data Manipulation
* Basic Software Design

---
